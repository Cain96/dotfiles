# Actively Utilize Skills

- Tasks requiring specialized knowledge → Read `SKILL.md` before starting work and apply the procedures/constraints as specified. Do not just declare it; actually use it.
- For small tasks where no relevant Skill exists, proceed with the normal flow.
- When using a Skill, explicitly state which one you're using and why in one line before proceeding.
